# 幻彩灯带控制板 · 使用手册

（ESP32-C3 SuperMini · BETAFPV PAVO 20 Pro）

幻彩灯带控制板为穿越机设计，轻量化、多功能。仅使用ESP32-C3 SuperMini，可以控制2812 LED灯带，并可以连接BetaFlight飞控输出的LED strip信号脚。全部功能：接收飞控 LED 信号、10 种模式、单键操作、灯数标定、断电记忆。硬件仅 **ESP32-C3 SuperMini**，无外接按键、无电平转换，工作电压 5V 。

> 固件为 **ESP-IDF 原生独立固件**（非 WLED、非 Arduino），零第三方依赖，Ver 16 无 WiFi / 无网页控制。V28 有热点，可网页控制。

---

## 一、硬件清单（BOM）

| 器件 | 规格 | 备注 |
|---|---|---|
| 主控 | ESP32-C3 SuperMini | 板载 USB 串口 + BOOT 键 |
| 灯带 | WS2812B COB 3mm，100 灯/米 | 长 ≤55cm → 55 颗 |
| 信号线 | 3 根（5V / GND / DATA） | 尽量短，与电机线分离 |

## 二、接线（务必看全）

| 来源 | 接到 |
|---|---|
| DC-DC 输出 **5V** | SuperMini **5V** + 灯带 **5V** |
| DC-DC **GND** | SuperMini **GND** + 灯带 **GND** + 飞控 **GND** |
| 飞控 LED 焊盘（3.3V 信号，T6 脚） | SuperMini **GPIO4** |
| SuperMini **GPIO3** | 灯带 **DIN**（数据） |
| 板载 BOOT 键（GPIO9） | 唯一按键，无需接线 |

> **共地是硬要求**：飞控 GND、DC-DC GND、SuperMini GND、灯带 GND 必须连在一起，否则飞控信号无参考基准会花屏/不亮。
> 引脚约定：**GPIO3 = 灯带数据（TX）**、**GPIO4 = 飞控信号（RX）**、**GPIO9 = BOOT 按键**；GPIO18/19 是 USB 引脚，勿复用。

## 三、供电要求（常见翻车点）

- 55 颗灯带**全白峰值约 3.3A**（≈60mA/颗），DC-DC 模块 **3A 起步**，追求满亮请用 5A；
- **USB 口供电带不动整条灯带**（电流不够 → 灯带完全不亮或极暗）。裸板测试建议：**只接 10~15 颗灯**，或灯带用独立 5V/3A 电源；
- 灯带 5V 与 GND 不要接反，否则烧灯珠。

## 四、在线编译（GitHub Actions，无需装软件）

1. 登录 [GitHub](https://github.com)，把工程推送到你的仓库（`src/`、`.github/`、`platformio.ini` 等**全部内容**）；
2. 打开仓库 **Actions** 页：push 会自动编译（也可点 **Run workflow** 手动触发）；
3. 编译完成（绿色 ✓）后，进入**本次运行**页面，下载构件 **pavo20-led-firmware**；
4. 构件里刷 **`merged.bin`**（合并固件）即可。

> **确认版本**：编译列表**顶部第一条**是最新的；日志开头 `=== 幻彩灯带控制板 v6 ===` 的 v 字号代表版本，看不到最新号说明刷的是旧构件。

## 五、网页刷机

1. 浏览器打开 **https://esptool.spacehuhn.com/**；
2. **Connect** 选择 SuperMini 串口（按住 BOOT 再插 USB 更稳）；
3. 加载 **`merged.bin`**，**Program** 等待完成。

> **关键**：C3 刷机**只保留一个槽 0x0000 **——在 "Erase Flash" 后 Program `merged.bin`，不要使用页面默认的 0x1000/0x8000/0xe000/0x10000 四个槽布局（那是 ESP32 经典版用的）；`merged.bin` 已包含 bootloader+分区+应用，刷一次即可。

## 六、串口监视（看日志）

1. 浏览器打开 **https://serial.huhn.me**（波特率 115200）；
2. **Connect** 后，**按一下板子复位键**——因为连接会重置 USB，按复位才能看到从第一行开始的完整日志；
3. 日志开头会显示版本、灯数、比例、`LED init=OK err=0x0` 和每秒 `[LED] tx=xx/s` 发送心跳。

## 七、操作（单键手势）

| 手势 | 功能 | 说明 |
|---|---|---|
| 单击 | 切换模式 | 0~9 循环 |
| 双击 | 切换颜色 | 白/红/黄/蓝/绿/青/品红/关 |
| 三击 | 切换速度 | 快 / 中 / 慢 |
| 长按 0.8s | 切换亮度 | 100% → 75% → 50% → 25%（保持按住每 0.5s 续切） |
| 长按 3s | 标定灯数 | 进入 / 退出灯珠数量标定（见第九节） |

> 长按 3s 过程中会在 0.8s 先切一次亮度，属正常现象。

## 八、模式与裸板调试（Bench 模式）

**开机固定进入本地灯效（模式 1 单色常亮）**，不依赖飞控即可上电看灯、按键把玩：

| 模式 | 名称 | 效果 |
|---|---|---|
| 0 | Betaflight | 显示飞控 LED 信号；无信号 >0.5s 灭灯 |
| 1 | 单色常亮 | 当前颜色常亮 |
| 2 | 单色呼吸 | 当前颜色呼吸 |
| 3 | 单色跑马 | 一条亮带单向跑 |
| 4 | 双边跑马 | 两条亮带同向跑 |
| 5 | 单色导向 | 带渐变尾巴的光点移动 |
| 6 | 单色增长 | 逐颗点亮循环 |
| 7 | 彩虹呼吸 | 整条彩虹色呼吸 |
| 8 | 彩虹渐变 | 沿灯带彩虹 + 流动 |
| 9 | 双边彩虹 | 从中间向两侧彩虹 |

**飞控自动接管**：任意模式下，GPIO4 检测到飞控信号即自动显示飞控灯；信号丢失超过 0.5s 自动回到当前灯效（模式 0 无信号则灭灯）。

**断电记忆**：颜色 / 速度 / 亮度 / 标定灯数掉电保存；**模式不记忆**（开机固定模式 1，方便裸板调试）。

## 九、灯珠数量标定

1. 长按 3s 进入标定（灯带前 N 颗亮白 = 当前标定值，默认 55）；
2. 在 Betaflight 的 LED 灯带配置页把灯珠设成 **红 / 蓝** 组合代表实际数量：**每颗红 = 实际 2 颗、每颗蓝 = 实际 4 颗**。例如实际 55 颗 → 设 23 红 + 2 蓝（23×2+2×4=54，再补 1 颗任意色），或 28 红（56）；
3. 灯带实时刷新显示标定结果（前 N 颗白）；全白闪烁 = 标定数超过灯带长度，需重新设置；
4. 长按 3s 退出，自动保存（断电不丢），并打印 Betaflight 应设的灯珠数。

## 十、Betaflight 配置（接飞控 T6）

1. 飞控 CLI 输入 `resource`，确认存在 **`LED_STRIP 1 A08`**（T6 配成 LED_STRIP 后输出 **WS2812 800kHz 协议**，不是串口信号）；
2. LED 灯带配置页：灯珠数按标定提示设置——55 颗灯带、1:2 比例 → 设 **28 颗**（28×2=56 ≥ 55）；布局按灯带实际环绕方向调整，勾选需要的状态灯功能；
3. 保存后，模式 0 下飞控信号实时上灯带。

> 比例由固件按标定灯数自动选择：≤32 颗 → 1:1，≤64 颗 → 1:2，≤128 颗 → 1:4。Betaflight 侧灯珠数 = 实际灯数 ÷ 比例，向上取整。

## 十一、故障排查

| 现象 | 排查 |
|---|---|
| 灯完全不亮 | ① 供电：55 颗全白 3.3A，USB 带不动，用独立 5V/3A 电源或只接 10~15 颗；② 接线：DATA 接 GPIO3、5V/GND 接对、**共地**；③ 刷机版本：日志开头应为最新 v 字号 |
| 日志看不到 build/开头几行 | 正常现象：USB 串口连接后才就绪。**Connect 后按一次复位键**，从第一行看 |
| `[LED] tx=0/s ok=0 err=0x1xx` | TX 通道初始化失败。`0x106` 是 C3 RMT 不支持 DMA（当前固件已修复）；其他错误码发日志排查 |
| 日志出现 `task_wdt` / IDLE 饿死 | 已修复（主循环忙转 + GPIO4 悬空噪声），刷最新版即可 |
| 颜色与飞控设置不符 | 个别灯带色序不同：改 `src/led_out.cpp` 中 `bytes` 数组顺序（GRB → RGB 等） |
| 上电按住 BOOT 进下载模式 | 正常现象，不是故障 |

## 十二、关键参数

| 项目 | 值 |
|---|---|
| RMT 时钟 | 40MHz（XTAL；C3 不支持 80MHz 分辨率，也不支持 DMA） |
| 时序 | T1H=800ns / T1L=450ns / T0H=400ns / T0L=850ns，复位 80µs |
| 灯数 | 默认 55，标定范围 ≤128（红×2 / 蓝×4） |
| 飞控最大灯珠 | 32 颗/帧 |
| 信号超时 | 0.5s 回本地灯效 |
| 版本标记 | 日志 `=== ... v6 ===`（当前可用固件 commit `458d420`） |

## 十三、固定方式建议（PAVO 20 Pro 机架）

- **灯带**：背胶沿机臂下沿/圈梁外侧贴一圈（DIN 端靠近飞控，信号线最短）；每约 10cm 用热熔胶点封防震脱落，勿压电机线、远离图传天线；
- **SuperMini**：拆排针约 1.5g，3M 双面胶贴中心板空闲处；固件无 WiFi，无干扰问题；
- **DC-DC**：贴机臂下侧/中心板下方，与飞控隔开；MP1584 注意电感散热；
- **信号线**：飞控 → GPIO4 尽量短（<10cm），与电机线保持距离；
- 整机增重 ≈ 15g 内，对 PAVO 20 Pro 影响很小。
