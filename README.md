# 幻彩灯带控制板（ESP32-C3 SuperMini · PAVO 20 Pro）

复刻「幻彩灯带使用说明书」控制板的全部功能，硬件只有 **1 个 5V 降压模块 + 1 颗电容 + 板载 BOOT 键**，无电平转换、无外接按键。

> 固件基于 **ESP-IDF 原生框架**（非 Arduino/WLED），零第三方依赖；日志经 SuperMini 内置 USB 串口输出。

## 一、接线

| 来源 | 接到 SuperMini / 灯带 |
|---|---|
| 电池 3S（XT30 或飞控电源焊盘，6~18V） | DC-DC 模块 IN+ / IN- |
| DC-DC 输出 5V | SuperMini **5V** 引脚 + 灯带 **5V** |
| DC-DC GND | SuperMini **GND** + 灯带 **GND** + 飞控 **GND**（必须共地） |
| 飞控 LED 焊盘（3.3V 信号） | SuperMini **GPIO4** |
| SuperMini **GPIO3** | 灯带 **DIN** |
| 板载 BOOT 键（GPIO9） | 唯一按键，无需接线 |

> 共地是硬要求：飞控 GND、DC-DC GND、SuperMini GND、灯带 GND 必须连在一起，否则飞控信号无参考基准会花屏。

## 二、固定方式建议（PAVO 20 Pro 机架）

- **灯带**：3mm 灯带自带背胶，沿四个机臂下沿 / 圈梁外侧贴一圈（起点 DIN 端靠近飞控侧，信号线最短）。背胶只负责定位，**首尾和每约 10cm 用热熔胶或 AB 胶点封**，防震动脱落；机臂有槽位的地方可再加 1.5mm 扎带加固。
- **避免**：不要贴进桨盘平面、不要压住电机线、远离图传天线走线。
- **SuperMini**：拆排针后约 1.5g，用 3M 双面胶贴在中心板上方空闲处（天线朝机架外侧伸出，远离碳纤板，碳纤会屏蔽信号）；飞行时 WiFi 本固件不启用，无干扰问题。
- **DC-DC 模块**：贴机臂下侧或中心板下方，与飞控隔开；若用 MP1584 注意电感体积和散热。
- **信号线**：飞控到 GPIO4 的线尽量短（<10cm），与电机线保持距离，必要时双绞。
- **整机增重**：SuperMini 1.5g + DC-DC ~5g + 55cm 灯带 ~7g + 线 ≈ **15g 内**，对 PAVO 20 Pro 影响很小。

## 三、在线编译与烧录（推荐，无需安装任何软件）

工程内置 GitHub Actions 编译脚本，全程网页操作：

1. 注册/登录 [GitHub](https://github.com)（免费），新建一个仓库（Public 或 Private 均可）；
2. 把本文件夹内**全部内容**（含 `.github` 目录）上传到仓库：
   - 网页方式：仓库页 → Add file → Upload files，把 `platformio.ini`、`README.md`、`src/`、`.github/` 拖进去提交；
   - 或命令行方式：`git init && git add . && git commit && git push`；
3. 打开仓库的 **Actions** 页：编译会自动开始（push 触发）；若没自动开始，点 **Run workflow** 手动触发；
4. 编译完成后（约 5~10 分钟，首次要下载工具链），在本次运行页面底部下载 **pavo20-led-firmware** 构件，里面有：
   - `merged.bin` —— 合并固件（**刷这个就行**）
   - `firmware.bin` —— 应用程序固件
5. 网页刷机：浏览器打开 [ESP Web Flasher](https://esp.huhn.me)：
   - 选择 **ESP32-C3** → **Connect** → 选 USB 串口（SuperMini 按住 BOOT 插 USB 更稳）；
   - 加载 `merged.bin` → **Program**，等待进度条完成即可。

> 本地方式（备选）：安装 VS Code + PlatformIO 插件打开本文件夹，点 Build / Upload；点 Monitor 可看日志（115200）。

## 四、操作（单键手势）

| 手势 | 功能 | 说明 |
|---|---|---|
| 单击 | 切换模式 | 10 种循环：Betaflight → 单色常亮 → 单色呼吸 → 单色跑马 → 双边跑马 → 单色导向 → 单色增长 → 彩虹呼吸 → 彩虹渐变 → 双边彩虹 |
| 双击 | 切换颜色 | 白/红/黄/蓝/绿/青/品红/关 |
| 三击 | 切换速度 | 快/中/慢 |
| 长按 0.8s | 切换亮度 | 100% → 75% → 50% → 25%（保持按住每 0.5s 继续切） |
| 长按 3s | 标定灯数 | 进入/退出灯珠数量标定（见第六节） |

> 长按 3s 的过程中会在 0.8s 先切一次亮度，属正常现象。

## 五、Betaflight 配置

1. 飞控连 Betaflight Configurator，进 CLI 输入 `resource`，确认存在 `LED_STRIP 1 A08`；
2. 打开 **LED 灯带** 配置页：
   - 灯珠数量：**按标定提示设置**（55 颗灯带、1:2 比例 → 设 **28 颗**，28×2=56 ≥ 55）
   - 布局按灯带实际环绕方向调整，勾选需要的状态灯功能（解锁/低电/方向等）；
3. 保存后，模式 0（Betaflight 模式）下飞控信号实时上灯带；无信号超过 0.5s 灯带熄灭。

> 比例是固件按标定灯数**自动选择**的：≤32 颗→1:1，≤64 颗→1:2，≤128 颗→1:4。Betaflight 侧灯珠数 = 实际灯数 ÷ 比例，向上取整。

## 六、灯珠数量标定

1. 长按 3s 进入标定（灯带前 N 颗白 = 当前标定值，默认 55）；
2. 在 Betaflight 的 LED 灯带页把灯珠设置成**红/蓝**组合来代表实际数量：每颗红=2 颗实际、每颗蓝=4 颗实际。例如实际 55 颗 → 可设 23 颗红 + 2 颗蓝（23×2+2×4=54，再补 1 颗任意色），或 28 颗红（56）；
3. 灯带会实时刷新显示标定结果（前 N 颗白）；若全白闪烁 = 标定数超过灯带长度，重新设置；
4. 长按 3s 退出，自动保存（断电不丢），并打印提示 Betaflight 应设的灯珠数。

## 七、说明与注意事项

- **供电**：55 颗灯带全白峰值约 3.3A，DC-DC 选 3A 起步；若追求满亮度全白请换 5A 模块。
- **色序**：飞控/固件按 WS2812 原生 GRB 处理；若灯带颜色与飞控设置不符（个别灯带色序不同），改 `led_out.cpp` 中 `bytes` 数组顺序。
- **引脚**：GPIO18/19 是 SuperMini 的 USB 引脚，勿复用；GPIO2/8/9 是 strapping 引脚，本方案已避开（GPIO9 用作按键）。
- **刷机**：上电时按住 BOOT 会进入下载模式，属正常，不要误以为是故障。
- **掉电保存**：模式/颜色/速度/亮度/标定灯数均存 flash（Preferences），断电记忆。
