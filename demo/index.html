灯带控制板 · 4 套界面方案

四套都是可点的真页面（用假数据模拟，没连设备），功能集一致：模式、颜色、速度、亮度、灯带长度、 Betaflight 入口、固件升级、无线空闲倒计时。差别在信息组织方式和视觉语言。 每套都能滚动、能点、能切换，建议在手机上也开一遍——这页面最终是在手机上用的。 差异最大的是 C（户外大按钮）和 B（亮色）——不是换配色，是换了操作方式； A 最接近你现在看到的，改动最小、风险最低；D 是唯一把「连接状态」单独成页的，调飞控时最省事。 也可以混搭，比如「A 的配色 + C 的按钮尺寸」。

选好后告诉我编号，我按那套重写固件里的页面（顺便把关闭 WiFi 那套逻辑整个换掉）。

方案 A · 深色面板 延续现有配色

沿用现在的深灰 + 琥珀色，但重排了信息层级：顶部状态三格一眼看完，模式两列编号排列，亮度和速度并排省滚动。改动最保守，熟悉感最强。

单独打开 →

方案 B · 亮色极简 白天看得清

白底浅灰分组、系统蓝强调，大圆角、无边框。户外强光下比深色底可读性好很多，代价是夜里会有点刺眼。分段控件操作最接近原生 App。

单独打开 →

方案 C · 户外大按钮 戴手套能按

为飞场设计：按钮放大到 64px 以上，高饱和青绿、强对比，字大、留白多。一屏只看得到主要控件，要滚动，但站着单手戴手套不会点错。

单独打开 →

方案 D · 三页分区 不再长滚动

顶部分「灯光 / 连接 / 设备」三页，每页只放自己那类东西。功能一多也不乱，代价是看全貌要多点两下。如果以后还要加参数，这套最好扩。
